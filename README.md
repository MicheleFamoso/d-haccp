# d/HACCP - Backend

**d/HACCP** è il backend per un'applicazione gestionale dedicata alla digitalizzazione dei controlli HACCP per ristoranti e aziende alimentari. Fornisce un'API RESTful sicura e strutturata, pensata per integrarsi facilmente con il frontend React.

---

## 🔧 Funzionalità principali

- 🧾 **Registrazione e login degli utenti** con hashing delle password
- 🏢 **Gestione ristoranti e sedi associate** a ciascun account
- 📋 **Registrazione delle attività giornaliere**: pulizie, temperature, fornitori
- 📦 **Gestione fornitori e scadenze**
- 🐞 **Controlli infestanti**
- 🔐 **Autenticazione JWT** e protezione delle rotte
- 🧠 **Struttura modulare e scalabile**

---

## 🛠️ Stack tecnologico


- **Java 17**
- **Spring Boot**
- **Spring Data JPA**
- **Spring Security (se implementata)**
- **PostgreSQL**
- **Maven**
- **RESTful API**
- **JWT** – Autenticazione stateless con token
- **Bcrypt** – Per l'hashing sicuro delle password
- **Cors** – Per la comunicazione frontend/backend
